## Role Definition

A security champion at [Organization Name] is a senior or mid-level engineer who serves as the security liaison for their product team. Champions are engineers first — they retain their full engineering responsibilities. The security champion role is an additional responsibility, not a reassignment.

> **In one sentence:** A security champion is the first point of contact for security questions within their team and the communication bridge between their team and the central security team.

---

## Scope

### In scope
- [ ] (Define 3–5 activities that are in scope)
- Triaging and remediating medium-severity vulnerabilities surfaced in the team's services
- Reviewing pull requests that touch authentication, authorization, input handling, or secrets management
- Participating in the security guild (monthly) and annual security champion summit
- Representing the team's security posture in quarterly security reviews

### Out of scope
- [ ] (Define 3–5 activities that are NOT in scope)
- Performing penetration tests or offensive security assessments
- Approving security policy exceptions (exceptions require central security team sign-off)
- Owning incident response for severity-1 security incidents (this remains with the security team)
- Security review for other teams (champions own their team's scope only)

## Selection Criteria

Champions are selected based on the following characteristics:

| Criterion | Description |
|-----------|-------------|
| Voluntary participation | Champion role must be self-selected or accepted willingly — mandatory appointment produces poor outcomes |
| Security interest | Demonstrated curiosity about security — has flagged a security concern, asked security questions, or pursued security reading independently |
| Seniority and influence | Mid-senior level; able to influence team behavior without positional authority |
| Communication skills | Effective written and verbal communicator; able to explain security requirements without alienating teammates |
| Availability | Not on a team in an active delivery crunch that would leave no capacity for champion activities |

---

## Reporting Structure

Security champions report to their **engineering manager** for performance reviews. The security team provides:
- Technical guidance and escalation support
- Training curriculum
- Recognition and visibility into the broader security program

The dual-reporting structure keeps champions embedded in their teams while ensuring accountability to the security program.
